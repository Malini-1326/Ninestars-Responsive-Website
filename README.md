# Ninestars – Responsive Website

A responsive website built using HTML, CSS, Bootstrap, and JavaScript with a clean and mobile-friendly design.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap
- JavaScript
- Media Queries

## ✨ Features

- Responsive navigation bar
- Responsive hero section
- About section
- Services section
- Portfolio section
- Team section
- Contact section
- Mobile-friendly layout
- Bootstrap responsive components
- Clean and structured UI

## 📱 Responsive Design

The website is designed to work across different screen sizes including:

- Desktop
- Tablet
- Mobile

Media queries and Bootstrap responsive utilities are used to provide a consistent user experience across devices.

## ▶️ How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/Malini-1326/Ninestars-Responsive-Website.git
cd Ninestars-Responsive-Website
```

### 2. Open the Website

Open the `index.html` file in your browser.

You can also use the **Live Server** extension in Visual Studio Code.
